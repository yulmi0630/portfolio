풀필먼트 운영의 의사결정을
데이터·AI로 자동화합니다.

본 사이트는 직접 구축한 AI 데이터 파이프라인과 KPI 대시보드 결과물 2종을 모은 곳입니다. SCM 운영기획 영역에서 매주 반복되는 분석·진단·액션 도출 과정을 표준 흐름으로 자동화할 수 있는지 검증하기 위해 만들었습니다.

Why

왜 만들었나

현장에서 매주 반복해온 SCM 운영 데이터 검토를 "진단 → 문제 정의 → KPI → 액션 → 검증"의 표준 흐름으로 자동화하면, 1인 PM 체계에서도 의사결정 속도와 일관성을 높일 수 있다는 가설에서 출발했습니다.

01

현장 페인포인트

매월 반복되는 KPI 검토·이슈 진단·액션 도출에 평균 8~12시간 소요. 분석자별 기준 편차로 의사결정 일관성 저하.

02

구조 가설

운영 데이터 → 진단 → 문제 정의 → KPI → 액션 인덱스 → 검증을 8단계로 표준화하면 LLM이 단계별 산출물을 안정적으로 만들 수 있다.

03

검증 결과

샘플 SCM 데이터 기준 8단계 파이프라인 + 의사결정 대시보드 자동 생성. 운영자가 클릭 한 번으로 트렌드·경보·액션 확인 가능.

AI 데이터 파이프라인 대시보드

scm-data-v1 · 8단계 자동 분석 → 의사결정 가이드

샘플 SCM 데이터를 입력하면 프로파일링 → EDA → 진단 → 문제 정의 → KPI → 임팩트 → 액션 → 대시보드까지 8단계를 LLM이 순차 생성합니다. 대시보드는 KPI 트렌드, 게이트 경보, 액션 인덱스, 검증 결과를 단일 페이지로 보여줍니다.
