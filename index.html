Why

왜 만들었나

현장에서 매주·매월 반복해온 SCM 의사결정(진단 · KPI · 액션 · 예측)을 표준 구조로 묶으면, 1인 PM 체계에서도 일관성과 속도를 동시에 확보할 수 있다는 가설에서 출발했습니다.

01

현장에서 겪은 일

매주·매월 반복되는 KPI 검토·재고 이슈 진단·액션 도출·예측 수립에 평균 8~12시간이 소요됐고, 분석하는 사람마다 기준이 달라 의사결정이 일관되지 못했습니다.

02

가설

SCM 운영기획의 핵심 의사결정 흐름을 표준 분석 뷰 · 표준 단계 · 표준 예측 흐름으로 묶으면, 한 명이 PM처럼 일하는 환경에서도 매번 같은 품질의 결정을 빠르게 낼 수 있다.

03

만든 결과

샘플 운영 데이터 기준 3가지 접근으로 검증. 풀필먼트 운영의 핵심 운영 지표 12종(재고일수 · 서비스율 · 납기·수량 충족률 · 예측 오차 · 회전율 · 4M 등)을 단일 흐름에서 진단 → KPI → 액션 → 예측까지 자동 생성.

대시보드 3종

세 대시보드 모두 본인이 만든 샘플·모의 데이터로 구동되며, 라이브 환경에서 직접 클릭해 보실 수 있습니다. 실제 회사 데이터는 포함되어 있지 않습니다. 각 작품은 운영 의사결정의 서로 다른 단계 — 분석 뷰 통합 · 자동 분석 · 수요 예측 — 을 다룹니다.

4개 분석 뷰 통합 대시보드

재고·수요예측·리드타임·물류비 한 페이지에서 의사결정

한 페이지에서 재고 건전성 · 수요 예측 · 공급업체 리드타임 · 물류비 4개 분석 뷰를 통합한 의사결정 대시보드. 각 뷰는 AI 분석 근거 패널(AI가 어떤 데이터를 보고 어떤 결정을 내렸는지 운영자가 검증 가능)과 현황 → 원인 → 결과 → 액션 4단계 내러티브로 의사결정을 가이드. 안전재고 시뮬레이션(서비스 수준 90/95/99%)·보충 큐 상위 8개 SKU·부족분 9,616개까지 운영자가 바로 발주에 옮길 수 있는 단위로 정리.

8단계 자동 분석 대시보드

데이터 → 진단 → KPI → 액션 8단계 자동 생성

샘플 SCM 데이터를 넣으면 데이터 프로파일링 → 분포·이상치 확인 → 진단 → 문제 정의 → KPI 산출 → 임팩트 시뮬레이션 → 액션 도출 → 단일 페이지 의사결정 화면 8단계가 자동으로 진행. 마지막 화면에는 SKU 위험 9분면(매출 기여도 × 회전 속도로 자동 분류), 1·2·3순위 액션 큐, 재고일수·예측 오차·회전율 등 6개 운영 지표, 운영 지표 경보(주의/위험), 분석 기준 단일화가 통합됩니다.

Methodology

분석 흐름 진화

6단계 흐름(2026.04)에서 출발해 진단·임팩트·액션을 별도 단계로 분리한 8단계 구조(2026.05)로 진화시켰습니다. 두 흐름 모두 AI가 단계별 결과(요약값 + 설명문 한 쌍)를 생성하고, 후속 단계는 직전 결과를 입력으로 받아 안정적으로 다음 단계 결과를 만듭니다.

개선 흐름 · 2026.05 8 단계

분석 흐름 (진단·임팩트·액션 분리)

진단 → 임팩트 시뮬레이션 → 액션 우선순위까지 자동 생성용

  1. 01 데이터 파악 컬럼·타입·기간 프로파일링
  2. 02 분포·이상치 결측 · 이상치 · 기본 통계
  3. 03 진단 운영 지표 원본 + SKU 9분면 분류
  4. 04 문제 정의 어떤 문제부터 풀지 우선순위
  5. 05 KPI 산출 현재 운영 지표 값 · 경보 자동 발생
  6. 06 임팩트 시뮬레이션 액션 실행 전 결과 사전 검증
  7. 07 액션 도출 1·2·3순위 액션 큐 · 실행 계획
  8. 08 의사결정 화면 위 7단계를 한 화면에 통합

개선 포인트 3가지 ─ ① 진단 을 분포·이상치 단계와 분리해 SKU 9분면 등급화 도입, ② 임팩트 시뮬레이션 단계 신설로 액션 실행 전 결과 사전 검증, ③ 액션 도출 을 별도 단계로 분리해 1·2·3순위 실행 우선순위를 분석 기준 단일화 형태로 가시화.
